# 进阶版桌宠定制框架

## 1. 产品分层

### 升级基础款（默认）

- 38 帧声明式基础配方；
- 新宠物 2 张摸头过渡帧，总计 40 帧；
- 标准角色确认、八相位走路确认；
- 坐下、睡眠、醒来、拖拽、自拍、表情和摸头；
- 配置化招牌入口、专注计时等不新增图片的通用能力；
- `rendering_mode=sprite`。

普通“做一个桌宠”请求只交付这一层。

### 进阶版（必须明确要求）

先完成基础款，再根据角色形象追加版本化多帧动作。推荐候选：

| 能力 | 建议帧数 | 典型触发 | 核心验收 |
|---|---:|---|---|
| 招牌动作 | 3–4 | 菜单、陪打字 | 一眼能认出角色，不机械摆臂 |
| 专注工作 | 4–6 | 25 分钟专注循环 | 可循环、动作克制、不会乱跳 |
| 开心跳跃 | 4–5 | 菜单、庆祝 | 下压、起跳、腾空、落地、回稳 |
| 等待回应 | 3–4 | 菜单或外部显式触发 | 不读取输入内容，姿态自然 |
| 微表情包 | 6 | 菜单、动作台词 | 同一角色与构图，只改变眼眉嘴和脸颊 |
| 互动台词包 | 0 | 动作、摸头、菜单、陪伴行为 | 纯本地、防重复、有冷却、可按动作编辑 |
| 侧面走路 | 8 | 用户选择的走路样式 | 先确认侧身模型，与正面八相位并存 |

不要求机械凑齐；不符合角色形象的动作可以不做。
微表情包属于推荐的进阶图像包。互动台词与侧面走路属于进阶需求确认清单中的
可选项，必须取得客户明确选择；基础模板继续保持
`dialogue_system.enabled=false` 和 `extension_animations={}`。

### 基础与进阶共用的活动区域

右键“活动区域”属于 OnePic 窗口引擎，不是进阶动作包。基础版与进阶版都自动
具备该入口，但 `config/settings.json` 固定默认关闭且不预置机器坐标。用户开启后，
自主走动和追鼠标受矩形限制；手动拖动可越出矩形，仍保留屏幕防丢失边界。
开关与 `X, Y, 宽, 高` 只写入用户本机设置，不进入 `pet-config.json`、运行 manifest、
素材审批或分享暂存区，也不计入 40/65/73 帧。

### 帧数口径

- 升级基础款：38 帧基础配方 + 2 张摸头过渡 = 40 帧；
- 进阶标准样例：基础款 + 招牌 4 + 专注 6 + 跳跃 5 + 等待 4 + 微表情 6
  = 65 帧；
- 加选侧面走路：65 + 侧面八相位 = 73 帧；
- 互动台词不增加图片帧；
- 活动区域属于零帧运行设置，不增加图片帧；
- 八向视线不计入上述口径，未点名时始终为 0 帧。

### 独立实验选配

以下功能即使用户说“进阶版”也不能自动加入：

- 八向视线/鼠标视线跟随；
- Live2D、Cubism 或混合待机；
- 其他需要专用运行后端或显著增加素材量的能力。

八向视线只有用户在当前宠物请求中明确点名才启用。已有项目实践表明，即使
技术上可运行，也可能产生换脸感、斗鸡眼和持续干扰，因此不能把案例功能升级为
默认生产项。

## 2. 固定生产流程

```text
环境检查
  → 独立宠物工作区
  → 一张标准角色候选
  → 用户确认角色
  → 40 帧基础款与走路 GIF
  → 用户确认走路
  → 进阶需求确认清单
      ├─ 多帧动作/微表情：规则图集 → 拆帧 → GIF/联系表/哈希
      ├─ 侧面走路：一张侧身模型 → 用户确认 → 八相位/GIF/哈希
      └─ 互动台词：角色默认台词 → 气泡实机预览 → 配置哈希
  → 用户分别确认每个已选模块
  → 配置引用已确认版本
  → 素材/配置/流程/行为/窗口测试
  → staging 构建和 QA
  → 事务激活
  → 完整目录 ZIP 与隐私校验
```

基础款和扩展包是两个门禁。基础款通过不代表扩展自动通过；一批扩展确认也不能
连带批准其他批次。

### 进阶需求确认清单

收到“做进阶版”后先让客户勾选或明确接受以下模块，不能机械全加：

1. 招牌动作、专注工作、开心跳跃、等待回应、微表情包；
2. 是否额外提供侧面走路；默认保留正面走路，不做替换；
3. 是否启用纯本地互动台词与自定义聊天词；
4. 八向视线和 Live2D 必须再次单独点名，不因选择进阶版而启用。

历史素材、审批和旧成品包保留用于回滚。

## 4. 扩展包素材契约

- 每帧 560×500 RGBA；
- 一组 1–32 帧，固定声明顺序；
- 同组共享比例，普通动作共享脚底基线；
- 跳跃保留真实垂直位移；
- 四角透明，主体距边缘至少 5px；
- 无明显绿幕/色键残留；
- 标准角色是唯一身份锚点；
- 身体结构、脸型、发型、服装、配饰和材质跨帧一致；
- 图集必须生成 GIF、联系表和逐帧 SHA-256 报告。

建议使用 `tools/prepare_extension_sheet.py` 确定性拆帧，不复制角色专用脚本。

### 微表情六帧契约

推荐顺序为 `calm`、`skeptical`、`surprised`、`shy`、`pensive`、`happy`。
六帧保持相同身体、头部位置、镜头、衣服和配饰，只调整眼眉、嘴形、脸颊颜色等
微小表情；禁止为了表情换脸、缩放漂移或改变帽子结构。整组生成 GIF、联系表和
帧束哈希后单独确认。

### 侧面走路八相位契约

1. 先只生成一张右向侧身模型，检查厚度、头身比例、鼻口轮廓、衣服尾部和脚长；
2. 侧身模型经用户确认后，才能生成走路帧；
3. 顺序固定为 A 脚接触、下压、经过、抬升，B 脚接触、下压、经过、抬升；
4. 八帧共享画布、比例和脚底基线，必须有两脚交替、身体起伏和自然重心转移；
5. 左向默认由已确认右向帧镜像，除非角色存在不能镜像的文字或单侧标志；
6. 侧面走路作为独立样式加入右键选择，`replaces_forward_walk=false`；
7. 默认走路仍为正面；客户的正面/侧面选择按宠物保存。

## 5. 审批与哈希

扩展候选先在 `workflow.json.extension_approvals` 中登记为
`pending_user_review`，此时 `activation_allowed` 必须为 `false`。

用户确认后记录：

- 原始图集 `source_sha256` 和 `approved_source_sha256`；
- 最终有序帧束 `asset_sha256` 和 `approved_asset_sha256`；
- 用户确认原文和 UTC 时间；
- 预览路径、帧数和人工检查项。

不同批次可分别批准。激活时，每个当前启用项必须在任意已批准批次中找到完全匹配
的帧束哈希；没有匹配就失败。

侧面走路需要两级确认：

- `optional_side_walk.vN` 绑定单张侧身模型哈希；
- `extension_approvals.<pack>.items.side_walk_vN` 绑定八帧有序帧束哈希。

未确认侧身模型时不得生成八相位；未确认八相位时不得装配。互动台词不使用图片
帧束，但必须把规范化后的 `dialogue_system` 语义哈希、动作数、句数、确认原文和
时间写入 `workflow.json.feature_status.local_dialogue_vN`。任何默认台词、概率、
冷却或长度限制变化都需要重新预览与确认。

## 6. 运行时抢占规则

优先级从高到低：

```text
拖拽/摸头
  → 手动或键盘触发的扩展动作
  → 专注循环
  → 走路与基础表情
  → 待机
  → 明确选配的八向视线
```

扩展动作不得被待机视线覆盖；非循环动作播放完必须回到自主状态；专注循环取消或
完成后必须清理扩展计时器。

文字气泡不改变动作状态，跟随当前动作显示；自拍图片气泡、拖拽和窗口隐藏可抢占
文字气泡。手动触发默认必说，自主动作低概率说话，并通过全局冷却与最近句窗口
避免刷屏。

正面与侧面走路共用 `PetState.WALK`，但运行时根据用户保存的 `walk_variant`
选择不同八帧序列；运动速度、边缘转向和相位起伏逻辑保持一致。侧面右向素材在
向左移动时按配置镜像，不复制第二套图片。

## 7. 互动台词包

启用示例：

```json
{
  "dialogue_system": {
    "enabled": true,
    "bubble_duration_ms": 3400,
    "cooldown_ms": 2400,
    "no_repeat_window": 3,
    "speak_chance": {
      "manual": 1.0,
      "touch": 0.75,
      "companion": 0.55,
      "autonomous": 0.14
    },
    "lines": {
      "wave": ["你好～", "今天也请多关照"],
      "touch": ["轻轻的……很舒服"],
      "jump": ["开心到跳起来！"]
    }
  }
}
```

- 每个动作建议 3–6 句，单句不超过 60 字；
- 自定义台词通过右键“聊天词 → 编辑聊天词”按动作保存；
- 用户覆盖按 `pet_id` 写入本机设置，不进入分享包；
- 空覆盖表示关闭该动作台词，“恢复默认聊天词”删除当前宠物覆盖；
- 台词只显示预设文本，不读取键盘内容、不联网、不冒充 AI 对话；
- 构建器必须校验并把规范化配置写入运行清单。

      "frames": [
        "actions/extensions/side_walk_v1/side_walk_01.png",
        "actions/extensions/side_walk_v1/side_walk_02.png",
        "actions/extensions/side_walk_v1/side_walk_03.png",
        "actions/extensions/side_walk_v1/side_walk_04.png",
        "actions/extensions/side_walk_v1/side_walk_05.png",
        "actions/extensions/side_walk_v1/side_walk_06.png",
        "actions/extensions/side_walk_v1/side_walk_07.png",
        "actions/extensions/side_walk_v1/side_walk_08.png"
      ],
      "frame_duration_ms": 115,

## 9. VPet 类养成模块

养成是进阶版的可选领域模块，不是新的角色制作框架，也不自动要求新动作。模板必须
保持关闭；只有用户明确要求后，才可在当前宠物的 `pet-config.json` 中启用：

```json
{
  "care_simulation": {
    "enabled": true,
    "initial_coins": 60,
    "feed_cost": 8,
    "feed_amount": 24,
    "drink_cost": 2,
    "drink_amount": 28,
    "play_vitality_cost": 6,
    "play_happiness_gain": 14,
    "focus_reward_coins": 18,
    "focus_reward_experience": 10,
    "action_cooldown_ms": 900
  }
}
```

- 配置必须规范化后计算 SHA-256，并绑定
  `workflow.feature_status.vpet_care_v1` 的用户确认；
- 任何平衡参数变化都会使旧哈希失效，构建器和 Android 装配器必须拒绝打包；
- 存档按宠物隔离，只进入用户本地设置或 Android 应用私有存储；
- 喂食、饮水、玩耍、休息和专注奖励优先复用已批准动作；
- 若养成扩展需要新图片或新动作，继续执行进阶包的独立视觉审批；
- 不复制 VPet 源码、存档、二进制或素材。

## 10. 八向视线的选配边界

默认模板固定为：

```json
{
  "directional_mouse_follow": {
    "enabled": false
  }
}
```

只有用户明确点名后才允许增加九帧。验收要求：

- 中心加屏幕坐标八方向；
- 九帧身体、嘴形、表情、比例和基线保持稳定；
- 双瞳平行同向、间距稳定，禁止斗鸡眼；
- 只在 idle 生效；
- 建议中心死区 64px、切换稳定时间 160ms；
- 用户认为违和时直接独立关闭，不牵连其余扩展动作。

## 11. 统一 QA

除基础款检查外，进阶版必须额外验证：

- 每个多帧包的 GIF、联系表、逐帧哈希与用户确认完全匹配；
- 微表情六帧构图不漂移、身份不变、差异集中在五官和脸颊；
- 侧面走路模型先确认，八相位两脚交替、基线稳定、首尾可循环；
- 正面走路仍存在且默认启用，右键切换和用户偏好持久化通过；
- 互动台词动作映射、概率、冷却、防重复、屏幕边缘定位和恢复默认通过；
- 启用养成时，配置确认哈希、按宠物存档、数值边界、消费失败、奖励和双端入口通过；
- 当前未点名八向视线时，运行清单方向帧计数必须为 0；
- 基础帧、扩展帧和可选走路统一计入 `total_asset_frame_count`；
- 改变任何启用模块后都重新执行完整测试、源码烟测与分享包烟测。

## 12. 发布与复刻

激活前运行：

```powershell
.\.venv\Scripts\python.exe .\tools\pet_workspace.py validate <pet-id>
.\scripts\build_pet.ps1 -PetId <pet-id> -Activate
```

分享版只运行：

```powershell
.\scripts\release_pet.ps1 -PetId <pet-id> -Mode share-no-selfie
```

每次改变启用功能都重新构建 ZIP。交付发布报告、ZIP CRC/SHA 和隐私扫描结果，
不要复用旧包，也不要单独发送 EXE。

# 隐私说明

本说明用于保护未授权或不希望公开的图片。虚拟角色本身不等同于真人隐私；如果仓库所有者拥有角色与图片的公开使用权，可以在补充素材授权后将其作为公开演示素材。

## 默认边界

- 基础桌宠运行不访问网络，也不上传角色图片。可选智能陪伴的云聊天默认关闭，只有
  用户配置服务和密钥并主动点击发送时才联网；请求不包含角色图片、动画帧或其他
  App 数据；
- 用户照片只从本地 `user_assets/` 读取；登记原图时会保留私有原始副本并生成同分辨率 `source/selfie.png`；
- 虚构角色或只有旧生成素材、没有原始照片时可设置 `selfie_required: false`；
  框架不会要求占位图，激活时还会清除上一只宠物残留的全局自拍；
- `user_assets/` 图片默认被 Git 忽略；
- 程序只在当前用户本地应用数据目录保存窗口位置和显示尺寸。
- Android API Key 使用 Android Keystore AES-GCM 保存，Windows API Key 使用当前
  用户 DPAPI 保存；两端密文都绑定 `pet_id` 和规范化服务 origin，不写入聊天数据库、
  项目配置、日志或分享包。Android 陪伴数据被排除云备份与设备迁移；
- Android 陪伴页禁止系统截图。用户档案、记忆和最近历史默认不发送，只有用户勾选后
  才随本轮消息发送；历史即使开启也受最近 30 条和 24,000 字符双重上限约束；
- 烟测使用 `ONEPIC_SETTINGS_DIR` 和 `ONEPIC_COMPANION_DATA_DIR` 分别隔离设置与
  陪伴数据库/DPAPI 密文，不读写 `%LOCALAPPDATA%` 中的真实用户数据；发布脚本结束
  时会恢复进入脚本前的进程环境值。

## 三种打包模式

- `private-local`：本机使用，可携带自拍；
- `share-with-approved-selfie`：只有自拍文件 SHA-256 与明确许可完全匹配才携带；
- `share-no-selfie`：不携带自拍。

所有模式都禁止原始图片/视频、来源目录、参考集、候选、草稿和备份进入包。
`share-no-selfie` 仍可包含由已批准角色绘制的 `selfie` 动作动画帧；这些不是
原始自拍像素。只有工作区 `source/selfie.png` 属于需哈希许可或排除的原图。

## 公开前检查

1. 检查 `git status --ignored`，确认私人图片处于忽略状态；
2. 检查源码中不存在本机绝对路径、账号、密钥和个人信息；
3. 本地分享统一运行 `scripts/release_pet.ps1` 并选择隐私模式；
4. 检查 release report 的隐私扫描、ZIP CRC 和 SHA-256；
5. 如果私人图片曾经进入 Git 提交，不要只删除当前文件，应在公开前重建干净历史。

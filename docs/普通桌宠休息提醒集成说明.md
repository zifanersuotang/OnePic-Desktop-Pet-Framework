# 普通桌宠休息提醒集成说明

## 结论

休息提醒已经作为 OnePic 普通桌宠的可选应用级模块接入。同一个
`OnePicDesktopPet.exe` 持有一个 `PetWindow`、一个系统托盘和一张按需出现的提醒卡；
没有捆绑原独立 Companion EXE，也没有第二个角色窗口或第二套托盘。

角色仍使用普通 38+0–2 帧桌宠的已有动作。预告、提醒、完成、延期、跳过、庆祝和
重排通过 manifest 把语义状态映射到 `curious`、`wave`、`happy` 等已批准动作，
不要求再制作六张提醒专用角色图。持久提醒状态由带“完成 / 稍后 / 跳过”按钮的
真实 Qt 操作卡保存；角色动作和气泡只是短暂视觉提示。

## 用户入口

系统托盘和角色右键菜单均有“休息提醒 / 角色番茄钟”子菜单：

- 查看下一项与剩余时间；
- 启用或关闭当前角色的主动提醒；
- 预览下一项角色表现；
- 立即调用任一健康提醒；
- 开始或重启角色番茄钟；
- 单独暂停/恢复提醒，不影响桌宠跑动；
- 对当前提醒执行稍后或跳过；
- 主动开启声音、本地匿名计数或当前用户开机启动；
- 打开本地提醒数据目录。

“暂停跑动”和“暂停提醒”是两个明确分开的动作。养成菜单中的“给宠物喝水”也不等同
于本模块的“提醒我喝水”。

## 配置边界

每只角色的 `runtime/manifest.json` 可声明 `break_reminders`。新工作区模板已经包含
完整示例，但生产默认 `enabled: false`，避免安装后未经同意主动打扰。用户在菜单中
开启后，从开启时刻重新计算计划，不补发程序关闭期间积压的提醒。

核心结构：

```json
{
  "break_reminders": {
    "schema_version": 1,
    "enabled": false,
    "schedule": {
      "preview_seconds": 30,
      "pause_on_fullscreen": true,
      "reflow_on_idle": true,
      "idle_threshold_seconds": 300,
      "resume_grace_seconds": 120,
      "quiet_hours": {
        "enabled": true,
        "start": "22:30",
        "end": "08:00"
      },
      "reminders": []
    },
    "state_mapping": {},
    "dialogue": {},
    "sounds": {"enabled_default": false, "files": {}},
    "privacy": {
      "network_default": "off",
      "collect_window_titles": false,
      "statistics_enabled_default": false
    }
  }
}
```

支持的 `kind`：

- `micro_break`
- `long_break`
- `water`
- `sedentary`
- `custom`
- `pomodoro`

普通周期项使用 `interval_minutes`、`duration_seconds`、`preview_seconds` 和
`snooze_minutes`。番茄项使用 `work_minutes`、`break_minutes`、
`long_break_minutes`、`focus_sessions_per_long_break` 和可选 `auto_start`。

新模板内置但默认关闭的示例是：10 分钟微休息、30 分钟长休息、25/5/15 四轮番茄、
45 分钟喝水和 60 分钟久坐活动。客户交付时应按其作息调整，不应把所有计划一律强开。

## 番茄钟唯一真源

健康周期由 `break_scheduler.SchedulerEngine` 管理。番茄阶段不使用原休息提醒项目里的
简化算法，而是直接复用 OnePic 已有的 `companion.tools.PomodoroState`：

- 专注、短休息、长休息三阶段；
- 默认四轮进入长休息；
- 单调时钟、暂停/继续和一次性完成转换；
- 25/5/15 等时间完全由 manifest 配置。

同刻发生番茄阶段切换和健康提醒时，番茄切换优先，健康提醒按自身延期配置重新排队，
避免两张卡或连续弹窗。旧的陪伴中心手动计时器仍是用户主动打开的通用工具；新建角色
模板把旧 `focus_session` 默认关闭，减少自动计时入口冲突。

## 中断、优先级与恢复

调度器使用 `time.monotonic()`，不依赖用户修改的墙上时钟计算间隔。勿扰时段只使用
本地时分判断。

- 全屏：仅比较前台窗口和目标显示器矩形，不读取标题或内容；
- 离开：只调用 `GetLastInputInfo` 读取“距最后输入多久”，不读取按键或鼠标内容；
- 勿扰、全屏或离开期间：撤下活动卡，解除后以宽限时间重新预告；
- 长轮询间隙或系统暂停迹象：过期项目统一重排；
- 多项同时到期：只保持一个活动提醒，其余过期项进入宽限重排；
- 番茄阶段切换优先于长休息、久坐、喝水、微休息和自定义健康提醒。

角色拖拽、摸头和自拍不会取消持久提醒卡。系统提醒视觉入口不会调用
`_record_user_interaction()`，所以不会伪造用户摸宠物、推迟自动坐下/睡眠或改变养成节奏。
隐藏角色时卡片同步隐藏；重新显示角色且提醒仍有效时，卡片会恢复。

## 隐私与授权

- 默认离线，模块没有网络调用；
- 不采集窗口标题、输入内容、文件内容或用户行为文本；
- 声音默认关闭，只允许 manifest 根目录内的相对 `.wav`；
- 本地匿名计数默认关闭；开启后只记录 `complete`、`skip` 等事件数量；
- 用户开关按 `pet_id` 隔离，保存到 `%LOCALAPPDATA%\OnePicDesktopPet\break-reminders.json`；
- 开机启动只写 HKCU 当前用户启动项，不请求管理员权限；便携目录移动后会校验命令；
- 角色图和声音必须有授权，客户原图、源视频、候选和本机数据不得进入分享包；
- Android 当前不实现这套 Windows 托盘/Win32 提醒，Android 装配会明确移除
  `break_reminders` 并写入 `break_reminders_supported: false`。

本模块由同一用户的 Character Break Companion 原创状态机思路迁入；没有复制
Stretchly、Workrave 或 BreakTimer 的代码、品牌、素材或文案。若把本项目的 MIT 代码
再分发，仍须遵守根目录 `LICENSE`。

## 验证命令

```powershell
# 环境检查
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\check_environment.ps1

# 全部单元与离屏 GUI 测试
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1 -UnitOnly

# 真实 Windows Qt 加速 QA（只抓控件，不抓桌面）
.\.venv\Scripts\python.exe .\tools\qa_break_reminders.py `
  --output .\reports\break-reminder-integration-qa\<run-id>

# 公开演示便携版构建
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

设置 `ONEPIC_BREAK_TEST_MODE=1` 时，只有清单里的 `test_mode` 加速参数生效；生产默认
仍保留分钟级合理值。测试模式不应交给客户作为日常启动方式。

## 当前验证边界

已验证：纯调度状态转换、严格配置、默认隐私、同刻仲裁、现有 PomodoroState 阶段、
真实 Qt 提醒卡、托盘菜单、中文工程路径、Windows 11 单屏 DPR 1.5、源码烟测、构建器
传递与 WAV 打包、Android 明确降级。

未验证：真实游戏/反作弊环境、系统休眠唤醒、多显示器硬件、Windows 10、真实连续
等待 25 分钟、代码签名和长期数日稳定性。全屏探针的逻辑和真实 API 调用有证据，
但不能据此宣传“所有游戏兼容”。未签名 EXE 仍可能触发 SmartScreen。

# 桌宠素材规范

## 输入图片

- 建议人物完整、清晰，身体无遮挡；
- 背景与人物轮廓容易区分；
- 用户拥有使用和修改图片的权利；
- 原图先备份，任何处理都写入新文件。

## 动作与命名

应用通过 `assets/pet/manifest.json` 加载动作。当前包含：`idle`、`walk`、`sit`、`sleep`、`drag`、`selfie`、`wave`、`happy` 及多种表情。

所有派生帧应满足：

- PNG RGBA 透明背景；
- 同一画布尺寸；
- 同类站姿人物高度变化不超过可见范围；
- 脚底锚点稳定；
- 不出现多头、多手、多腿、跨格重影和身体裁切；
- 连续帧在实际显示尺寸下仍然清晰。

## 人物身份门禁

批量动作必须以用户明确确认的首张标准角色形象为唯一身份参考。生成风格可选择保留原画风、轻度 Q 版或完整 Q 版；确认前只生成候选，不生成动作。身份参考至少记录脸型、眼型、眉形、发型、服装和标志性配饰，避免不同人物被统一成相同模板脸。

开心、害羞、惊讶、生气、困倦、疑惑、自拍和拖拽等符号由程序透明图层绘制，不永久画入动作图片。惊讶动作采用微张嘴、单手轻放胸前的轻度反应，禁止双手高举和大张嘴的尖叫模板。

## 走路门禁

走路必须提供左右对称的八相位，而不是对一张站姿做轻微位移。自动检查通过后还要生成 `walk-preview.gif`，只有用户确认没有平移、滑步和跳帧，私有素材才允许加载和打包。

## 验证

演示素材先运行 `tools/prepare_assets.py`；本地素材在标准角色确认后运行 `tools/prepare_user_pet.py`。随后生成走路预览并运行 `scripts/test.ps1`。自动检查不能替代人工视觉验收。

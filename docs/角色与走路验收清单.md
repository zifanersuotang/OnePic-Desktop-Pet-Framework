# 角色与走路验收清单

## 首张标准角色形象

用户必须先看到单张、清晰、完整的标准角色候选，再决定是否继续。检查：

- 是否保留原图可辨识的脸型、眼型、眉形和笑容；
- 是否保留标志性发型、刘海、辫子、服装、配饰或随身物品；
- 是否保留人物原有气质，而不是套用项目演示角色的模板脸；
- 如果选择 Q 版可以简化比例，但不能把不同人物生成成同一张脸；选择保留原画风时不得擅自改成 Q 版；
- 惊讶动作不能双手高举或大张嘴尖叫，应使用轻度姿势并由小号“！”增强；
- 表情符号应由程序图层显示，换角色素材后仍然有效；
- 用户没有明确回复“确认”时，状态必须保持 `awaiting_user_confirmation`。

## 八相位走路

走路图集至少包含左右对称的八个阶段：

1. 右脚落地；
2. 右脚承重下压；
3. 左脚从身体下方迈过；
4. 左脚前摆、身体抬升；
5. 左脚落地；
6. 左脚承重下压；
7. 右脚从身体下方迈过；
8. 右脚前摆、身体抬升。

GIF 验收时检查：

- 左右腿是否真的交替，而不是同一姿势抖动；
- 落脚时鞋底是否稳定，人物是否像贴纸滑动；
- 身体重心是否有轻微下压和抬升；
- 长发、辫子、裙摆等是否存在自然的滞后摆动；
- 第八帧回到第一帧是否跳变；
- 运行时移动是否连续，没有停住后突然冲出的感觉。

## 基础动作候选的肢体完整性

每个动作独立审查 2–3 个候选，不合格帧不得作为下一轮修图底图。检查：

- 人形角色只有一对手臂和两只手，下半身可见时只有两条腿；动物按物种检查四肢与前后爪归属；
- 手、手腕、手臂与肩的连接清楚，被遮挡肢体的去向可以解释，没有从衣服、腿或道具中多长出一只手；
- 道具和鼠标只被应有的手握持，没有手指融进道具、道具复制或手掌重影；
- 当前帧只表达一个主动作，不同时叠加挥手、打字、拿物和起身等相互冲突的职责；
- 头发、服装、配饰、脸型和体型与 `candidate/approved.png` 一致；
- 轮廓没有重影、双曝光、残留手、断肢或被裁断的突出配饰。

任一项失败就停止当前批次，回到已批准标准角色重新生成。

## 自拍成片

- 照片内容必须来自最初登记的原图；
- 可以等比例缩放或套拍立得边框，但不能重新生成五官；
- 不得使用自拍动画末帧、标准角色候选或项目演示照片替代；
- 原图和自拍图只保存在 `user_assets/`，不得进入公开 Git 和公开 Release。

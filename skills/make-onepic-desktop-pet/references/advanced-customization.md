# 进阶版多帧扩展

只在用户明确提出进阶版、扩展动作或点名能力后执行。先完成并确认 40 帧基础款，
再追加扩展；不要让扩展素材阻塞基础款交付。

## 推荐进阶包

按角色形象筛选，不要求机械凑齐：

- 3–4 帧招牌动作：短、辨识度高，可绑定陪打字或菜单；
- 4–6 帧专注工作循环：绑定专注计时，必须可安全循环；
- 4–5 帧开心跳跃：包含下压、起跳、腾空、落地和回稳；
- 3–4 帧等待回应：克制、可手动触发，不读取用户输入内容；
- 6 帧微表情包：平静、狐疑、惊讶、害羞、沉思、开心，只改变面部；
- 0 帧互动台词包：动作绑定纯本地台词池，具备防重复、冷却和按宠物自定义。
- 8 帧侧面走路：独立选配，保留正面走路并允许客户切换。

八向视线不在推荐包内。只有用户明确说“八向视线、看鼠标、视线跟随”时才制作，
并单独确认；普通版或进阶版请求都不能自动启用。

## 生产目录

```text
actions/extensions/candidates/<pack>-vN-sheet-chroma.png
actions/extensions/candidates/<pack>-vN-sheet-alpha.png
actions/extensions/<pack>_vN/*.png
review/extensions/<pack>-vN/<pack>-preview.gif
review/extensions/<pack>-vN/<pack>-contact-sheet.png
review/extensions/<pack>-vN/<pack>-report.json
```

不得覆盖旧版本。只有确认后才把 `pet-config.json` 指向新目录；旧目录和旧成品包
继续保留。

侧面走路额外使用两级版本目录：

```text
candidate/side-model-vN.png
review/side-model-vN/
actions/extensions/side_walk_vN/*.png
review/extensions/side-walk-vN/
```

## 固定门禁

1. 以已批准标准角色为唯一身份锚点生成一张规则图集；
2. 去背后拆成 560×500 RGBA 帧，统一比例与基线；
3. 生成 GIF、联系表和逐帧 SHA-256 报告；
4. 检查身份、动作相位、裁切、绿边、循环和触发节奏；
5. 在 `workflow.json.extension_approvals` 登记
   `pending_user_review`，不得激活；
6. 用户明确确认后记录原图集哈希和最终帧束哈希；
7. 运行素材、配置、流程、行为和窗口测试，再事务激活；
8. 分享版重新运行完整发布脚本，不复用旧 ZIP。

不同批次可以分别批准。构建时每个启用项都必须在任一已批准批次中找到与当前帧束
完全匹配的 `approved_asset_sha256`；不能因为同批其他动作已确认而连带放行。

## 微表情包专用约束

固定六帧语义为 `calm`、`skeptical`、`surprised`、`shy`、`pensive` 和
`happy`。六帧必须共用同一身体、姿势、镜头、比例、服装和配饰，只允许眼睛、
眉毛、嘴形与适量腮红变化；禁止借微表情换脸、换动作或改变构图。

按一个独立扩展包生成 GIF、联系表和逐帧哈希。用户确认的是完整六帧包，不得把
未确认的单帧混入运行清单。

## 侧面走路专用约束

侧面走路是可选追加项，不能替换已批准的正面走路：

1. 先只生成一张向右侧身标准模型，检查头身比、厚度、鼻口轮廓、服装侧视结构和
   身份一致性；
2. 用户确认侧身模型后，才生成八相位走路；
3. 八相位固定为 A 脚接触、下压、B 脚迈步、抬升、B 脚接触、下压、A 脚迈步、
   抬升，比例、基线和朝向必须一致；
4. 默认可镜像得到向左版本；角色文字、徽章、不对称发饰或其他方向敏感特征存在时，
   必须单独检查，不能盲目镜像；
5. 配置必须标记 `walk_variant: true`、`walk_variant_default: false` 和
   `replaces_forward_walk: false`；用户的切换偏好按宠物持久化；
6. 侧身模型确认与八帧走路确认分别绑定当前素材哈希，任一素材变化都使对应审批失效。

## 八向视线专用约束

仅在用户显式选配后使用：

- 中心加八方向共九帧，使用屏幕坐标语义；
- 九帧共用同一身体、嘴形、表情、比例和基线，只改变眼神；
- 左右瞳孔始终平行同向、间距稳定，禁止斗鸡眼；
- 眼神位移克制，头部最多轻微倾斜，不允许换脸或身体漂移；
- 默认建议 `dead_zone_px: 64`、`switch_delay_ms: 160`，避免乱跳；
- 只在 idle 生效，必须让位给走路、摸头和扩展动作。

用户未点名该功能时保持：

```json
{
  "directional_mouse_follow": {
    "enabled": false
  }
}
```

## 互动台词包

只有用户明确提出聊天气泡、随机台词或自定义聊天词时启用
`dialogue_system`。每个动作建议 3–6 句；手动触发必说，自主动作低概率说话，
并设置全局冷却和最近句防重复。用户覆盖按宠物保存在本机设置，分享包只包含角色
默认台词。启用前必须展示真实气泡预览，并把规范化后的台词、概率、冷却和映射计算
为语义配置哈希，记录在 `workflow.json` 后取得直接确认。该能力不读取按键内容、
不访问网络，也不等同于 AI 对话。

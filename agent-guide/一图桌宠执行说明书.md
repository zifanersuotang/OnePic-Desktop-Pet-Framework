# 一图桌宠 Agent 执行说明书

本文件是面向单图输入的简明入口。完整且优先级更高的流程见
`AGENT_GUIDE.md` 和 `../docs/可复用桌宠制作流程.md`。

## 1. 环境和独立工作区

```powershell
.\scripts\check_environment.ps1
.\scripts\setup_environment.ps1
.\scripts\new_pet.ps1 `
  -PetId "<pet-id>" -DisplayName "<name>" `
  -Source "<absolute-image-path>" -Mode full-body
```

默认 `RenderingMode` 为 `sprite`，也就是升级基础款：38 帧基础配方 + 新宠物
默认两张摸头过渡帧。用户没有明确提出 Live2D、Cubism 或混合版时，禁止主动
切换渲染路线。只有明确要求时才增加：

```powershell
-RenderingMode hybrid-live2d
```

每只宠物只使用 `user_assets/pets/<pet-id>/`。原图、自拍、候选、动作、预览、
运行帧和 `workflow.json` 均在该工作区内；全局文件只保存 active pet 指针。
图片会以原像素登记为私有自拍，原文件不得覆盖或进入分享包。

## 2. 两个人工门禁

只先制作一张标准角色，登记后向用户展示：

```powershell
.\.venv\Scripts\python.exe .\tools\onepic_workflow.py `
  --pet-id <pet-id> character-candidate `
  --image "user_assets/pets/<pet-id>/candidate/approved.png"
```

只有用户明确确认后才能运行 `approve-character`。随后制作八种动作、八相位走路，
以及新宠物默认的 `touch_soften.png`、`touch_return.png` 两张摸头过渡帧。
走路 GIF 或替代互动预览也必须由用户明确确认。两次确认都和当前素材 SHA-256
绑定，素材变化会自动使确认失效。

## 3. 38 帧基础 + 摸头默认两帧

基础配方固定为 idle 6、walk 8、sit 5、sleep 5、drag 3、selfie 4，以及
wave、happy、shy、surprised、annoyed、sleepy、curious 各 1，共 38 帧。
新宠物默认再制作两张摸头过渡帧，总计 40 帧；旧宠物迁移时可保留 0–2 张，
运行时用安全混合补足平滑回待机。

摸头默认播放 `surprised 320 ms → shy/happy 760 ms → 每张过渡 180 ms →
idle blend 160 ms`。分支默认按权重随机且不连续重复，播放期间连点忽略。

## 4. 装配、QA 和回滚

```powershell
.\.venv\Scripts\python.exe .\tools\pet_workspace.py validate <pet-id>
.\scripts\build_pet.ps1 -PetId <pet-id> -Activate
```

所有生成先进入 staging。只有门禁、alpha-mass/透明尺寸/走路/摸头 QA 和隔离
测试全部通过才激活。复核 `review/` 中的动作接触表、透明动作 PNG、walk GIF、
sit-sleep-wake GIF、touch-feedback GIF 和 `assets-qa.json`。失败不会替换
最近可用版本；需要时运行 `scripts/rollback_pet.ps1`。

所有 Windows 宠物同时继承默认关闭的右键“活动区域”。它不属于角色素材或进阶
动作：开启后只限制自主走动和追鼠标，手动拖动可越出矩形且不会在松手时跳回；
用户坐标只保存在本机设置，禁止写入宠物 manifest 或分享包。QA 要检查开启、
关闭、坐标持久化和多屏回退。

## 5. 一键发布

```powershell
.\scripts\release_pet.ps1 -PetId <pet-id> -Mode share-no-selfie
```

命令依次完成构建、测试、源码烟测、EXE、打包后烟测、隐私扫描、逐文件
CRC/SHA、ZIP CRC/SHA 和 release report。只交付完整 `OnePicDesktopPet/`
目录 ZIP，不单发 EXE。模式可选 `private-local`、
`share-with-approved-selfie` 或 `share-no-selfie`；原始参考、草稿、候选、
备份和未明确许可的自拍永不进入分享包。

# Live2D Web source boundary

This directory contains an HTML shell and build metadata for optional integration research only.

The public repository does **not** contain Live2D Cubism Core, a prebuilt JavaScript bundle, models, textures, or motions. Running or distributing this route requires the user to supply separately licensed dependencies and to review the applicable Live2D and JavaScript package licenses.

The default Sprite runtime and PyInstaller specification do not package this directory.
